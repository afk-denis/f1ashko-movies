# F1ashko — архив просмотров

Статический каталог записей стримов. Данные — из Google Sheets, только чтение. Отдельный приватный Apps Script синхронизирует оригинал и заполняет метаданные; секреты не входят в этот репозиторий.

## Публикация

В Settings → Pages → Build and deployment выберите Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml` читает актуальную таблицу, проверяет парсер и фильтры, публикует только каталог `site`. Запуск: push в main, вручную через Actions и дважды в час по расписанию (17-я и 47-я минуты; GitHub может задерживать расписание). Посетитель не обращается к API Кинопоиска.

Если чтение таблицы или тесты не удались, новая версия не публикуется. Старый успешный деплой остаётся доступным. Кнопка «Обновить данные сайта» перечитывает последний опубликованный снимок, не запускает импорт API.

## Возможности

Поиск по названию; фильтры по жанру, году, стране, актёрам, режиссёрам и формату. Внутренний поиск вариантов, множественный выбор, синонимы action/экшн/боевик и horror/ужасы. Между фильтрами — AND, внутри одного — OR. Пагинация 12/24/48/96, сортировка, карточки/список, мобильный интерфейс, случайный просмотр и состояние в URL.

Повторные просмотры сохраняются. Объединённые ячейки ссылок распространяются только на собственный диапазон объединения. Числовые ID вида 484470.0 нормализуются без округления. Предварительные `legacy`-жанры не восстанавливаются в очищенные ячейки. Результаты с `Фильм API = ok` имеют отметку подтверждения; неподтверждённые данные не выдаются за результат API.

## Локально

Python 3.10+ и современный Node.js, npm-пакеты не нужны.

```sh
python3 scripts/export_catalog.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.js
python3 -m http.server 8080 --directory site
```

Для офлайн-проверки экспортируйте таблицу в XLSX и передайте `python3 scripts/export_catalog.py --input /path/to/export.xlsx`. Не коммитьте приватные скрипты, API-ключи и XLSX. Публичный сайт получает только публичный JSON.
